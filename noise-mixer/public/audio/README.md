# Audio Files Directory

Place your looping audio files here. The app expects MP3 format but also supports WAV and OGG.

## Expected Files (from assets.json):
- `brown.mp3` - Brown noise audio track
- `rain.mp3` - Rain sounds audio track
- `fan.mp3` - Fan ambient sound
- `vinyl.mp3` - Vinyl crackle sound

## Recommended Encoding:
- Format: MP3 or WAV
- Bitrate: 128-192 kbps (MP3)
- Sample rate: 44.1 kHz or 48 kHz
- Channels: Stereo or Mono
- Duration: 30 seconds to 5 minutes (will loop seamlessly)
- Ensure files loop smoothly (fade out at end matches fade in at start)

## Where to Find Ambient Sounds:
- freesound.org (free, Creative Commons)
- mynoise.net (generate custom soundscapes)
- Create your own using Audacity (free audio editor)

## Note:
The app will continue to work if some files are missing, showing a warning icon for unavailable tracks.
